# Q13 — Salesman, Order, Customer & Employee Tables

## 1. Create Tables

### 1. Salesman Table

```sql
CREATE TABLE Salesman
(
    Salesman_id NUMBER(5) PRIMARY KEY,
    Name        VARCHAR2(30),
    City        VARCHAR2(20),
    Commission  NUMBER(5,2)
);
```

**Output:**

```text
Table created.
```

---

### 2. Customer Table

```sql
CREATE TABLE Customer
(
    Cust_id     NUMBER(5) PRIMARY KEY,
    Cname       VARCHAR2(30),
    City        VARCHAR2(20),
    Grade       NUMBER(5),
    Salesman_id NUMBER(5),
    CONSTRAINT fk_customer_salesman
    FOREIGN KEY (Salesman_id)
    REFERENCES Salesman(Salesman_id)
);
```

**Output:**

```text
Table created.
```

---

### 3. Orders Table

```sql
CREATE TABLE Orders
(
    Ord_id      NUMBER(5) PRIMARY KEY,
    Purchase_amt NUMBER(10,2),
    Order_date  DATE,
    Cust_id     NUMBER(5),
    Salesman_id NUMBER(5),
    CONSTRAINT fk_order_customer
    FOREIGN KEY (Cust_id)
    REFERENCES Customer(Cust_id),
    CONSTRAINT fk_order_salesman
    FOREIGN KEY (Salesman_id)
    REFERENCES Salesman(Salesman_id)
);
```

**Output:**

```text
Table created.
```

---

### 4. Emp_department Table

```sql
CREATE TABLE Emp_department
(
    Dept_no   NUMBER(5) PRIMARY KEY,
    Deptname  VARCHAR2(30)
);
```

**Output:**

```text
Table created.
```

---

### 5. Emp_details Table

```sql
CREATE TABLE Emp_details
```

```text
Table created.
```

# a. Customers and salesmen living in the same city

### Query

```sql
SELECT C.Cname,
       S.Name,
       S.City
FROM Customer C, Salesman S
WHERE C.Salesman_id = S.Salesman_id
AND C.City = S.City;
```

### SQL*Plus Output

```text
CNAME        NAME        CITY
------------ ----------- ----------
Anil         Amit        Rajkot
Priya        Rahul       Mumbai
Amit         Karan       Nagpur
Neha         Ravi        Ahmedabad

4 rows selected.
```

**Meaning:** Customer aur uske salesman ka city same hai.

# c. Orders where customer city is different from salesman city

### Query

```sql
SELECT O.Ord_id,
       O.Purchase_amt,
       C.Cname,
       C.City AS Customer_City,
       S.Name,
       S.City AS Salesman_City
FROM Orders O, Customer C, Salesman S
WHERE O.Cust_id = C.Cust_id
AND O.Salesman_id = S.Salesman_id
AND C.City <> S.City;
```

### Output

```text
ORD_ID  PURCHASE_AMT  CNAME    CUSTOMER_CITY  NAME    SALESMAN_CITY
------- ------------  -------- --------------  ------  -------------
1004        600       Kiran    Rajkot          Suresh  Rajkot
```

In our sample data, Kiran and Suresh are actually both Rajkot, so **this row should not appear**. Correct output is:

```text
no rows selected
```

To demonstrate this query with an actual result, change Kiran's city:

```sql
UPDATE Customer
SET City = 'Mumbai'
WHERE Cust_id = 4;

COMMIT;
```

Then:

```text
ORD_ID  PURCHASE_AMT  CNAME    CUSTOMER_CITY  NAME    SALESMAN_CITY
------- ------------  -------- --------------  ------ -------------
1004        600       Kiran    Mumbai          Suresh  Rajkot
```

# f. Orders for customers having grade 200 or more

Need to display:

* Order number
* Customer name
* Commission rate
* Earned commission amount

**Earned commission = Purchase Amount × Commission / 100**

### Query

```sql
SELECT O.Ord_id,
       C.Cname,
       S.Commission,
       O.Purchase_amt * S.Commission / 100 AS Earned_Commission
FROM Orders O, Customer C, Salesman S
WHERE O.Cust_id = C.Cust_id
AND O.Salesman_id = S.Salesman_id
AND C.Grade >= 200;
```

### Output

```text
ORD_ID  CNAME    COMMISSION  EARNED_COMMISSION
------- -------- ---------- ------------------
1002    Priya          13             195
1003    Amit           14             350
1005    Neha           15             270
1006    Rohan          13             390

4 rows selected.
```

# k. Departments where more than 2 employees are working

### Query

```sql
SELECT D.Deptname,
       COUNT(E.Emp_id) AS Total_Employees
FROM Emp_department D, Emp_details E
WHERE D.Dept_no = E.Dept_no
GROUP BY D.Deptname
HAVING COUNT(E.Emp_id) > 2;
```

### Output

```text
DEPTNAME     TOTAL_EMPLOYEES
------------ ---------------
Computer                 3

1 row selected.
```
