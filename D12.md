# (12) Emp_Mast, Dept_Mast & Salary_Mast

## 1. Create `Dept_Mast`

```sql
CREATE TABLE Dept_Mast
(
    Dept_no   NUMBER(3) PRIMARY KEY,
    Dept_name VARCHAR2(30)
);
```

## 2. Create `Emp_Mast`

```sql
CREATE TABLE Emp_Mast
(
    Emp_no    NUMBER(5) PRIMARY KEY,
    Emp_name  VARCHAR2(30),
    Dept_code NUMBER(3),
    Desi      VARCHAR2(20),
    CONSTRAINT fk_emp_dept
    FOREIGN KEY (Dept_code)
    REFERENCES Dept_Mast(Dept_no)
);
```

## 3. Create `Salary_Mast`

```sql
CREATE TABLE Salary_Mast
(
    Emp_no NUMBER(5),
    Sal    NUMBER(8,2),
    Hra    NUMBER(8,2),
    Ma     NUMBER(8,2),
    Pf     NUMBER(8,2),
    CONSTRAINT fk_sal_emp
    FOREIGN KEY (Emp_no)
    REFERENCES Emp_Mast(Emp_no)
);
```

# i. Display employee name, department name and total salary

Formula given:

**Total Salary = Sal + Hra + Ma − Pf**

Condition:

**Salary > 2000 and Salary < 5000**

### Query

```sql
SELECT E.Emp_name,
       D.Dept_name,
       S.Sal + S.Hra + S.Ma - S.Pf AS Total_Salary
FROM Emp_Mast E, Dept_Mast D, Salary_Mast S
WHERE E.Dept_code = D.Dept_no
AND E.Emp_no = S.Emp_no
AND S.Sal > 2000
AND S.Sal < 5000;
```

# ii. Update HRA

Question says:

* If employee salary **more than 2000** → HRA = **100**
* Otherwise → HRA = **200**

### Query

```sql
UPDATE Salary_Mast
SET Hra = CASE
            WHEN Sal > 2000 THEN 100
            ELSE 200
          END;

COMMIT;
```

# iii. Delete all employees from Emp_Mast having department "Computer"

First, find the department number for Computer and delete employees from `Emp_Mast`.

### Query

```sql
DELETE FROM Emp_Mast
WHERE Dept_code IN
      (SELECT Dept_no
       FROM Dept_Mast
       WHERE Dept_name = 'Computer');

COMMIT;
```

### SQL*Plus Output

```text
SQL> DELETE FROM Emp_Mast

  3        (SELECT Dept_no
  4         FROM Dept_Mast
  5         WHERE Dept_name = 'Computer');
```
