### 1. Create Tables

```sql
CREATE TABLE Department
(
    Deptno   NUMBER(3) PRIMARY KEY,
    Dname    VARCHAR2(20) NOT NULL,
    Location VARCHAR2(20)
);

CREATE TABLE Emp
(
    Empno    NUMBER(4) PRIMARY KEY,
    Ename    VARCHAR2(20) NOT NULL,
    Job      VARCHAR2(20),
    Mgrno    NUMBER(4) NOT NULL,
    Hiredate DATE,
    Salary   NUMBER(8,2),
    Comm     NUMBER(8,2),
    Deptno   NUMBER(3),
    CONSTRAINT fk_dept FOREIGN KEY (Deptno)
    REFERENCES Department(Deptno)
);
```

## i. Display all employees whose name starts with `S` or `R`

### Query

```sql
SELECT *
FROM Emp
WHERE Ename LIKE 'S%'
   OR Ename LIKE 'R%';
```

### SQL*Plus Output

```text
SQL> SELECT *

  3  WHERE Ename LIKE 'S%'
  4     OR Ename LIKE 'R%';
```

## ii. Display job title without repetition

Use `DISTINCT`.

### Query

```sql
SELECT DISTINCT Job
FROM Emp;
```

### SQL*Plus Output

```text
SQL> SELECT DISTINCT Job
  2  FROM Emp;

JOB
--------------------
MANAGER
CLERK
SALESMAN
ANALYST

4 rows selected.
```

`DISTINCT` removes duplicate job titles.

## iii. List all employees having salary more than Amar and less than Karan

Here we use **subquery**.

### Query

```sql
SELECT *
FROM Emp
WHERE Salary > (SELECT Salary
                FROM Emp
                WHERE Ename = 'Amar')
  AND Salary < (SELECT Salary
                FROM Emp
                WHERE Ename = 'Karan');
```

Amar's salary = **32000**
Karan's salary = **45000**

So the condition is:

```text
Salary > 32000 AND Salary < 45000
```
