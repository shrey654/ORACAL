### Tables

**Item_Master**

* Item_id
* Item_name
* Price
* Company_code

**Company_master**

* Com_id
* Com_name

## 2. Create `Item_Master` Table

```sql
SQL> CREATE TABLE Item_Master
  2  (
  3     Item_id      NUMBER(5) PRIMARY KEY,
  4     Item_name    VARCHAR2(30),
  5     Price        NUMBER(10,2),
  6     Company_code NUMBER(5),
  7     CONSTRAINT fk_item_company
  8     FOREIGN KEY (Company_code)
  9     REFERENCES Company_master(Com_id)

Table created.
```

# iii. Display average price of items of each company

Use `AVG()` and `GROUP BY`.

### Query

```sql
SQL> SELECT C.Com_name,
  2         AVG(I.Price) AS Average_Price
  3  FROM Item_Master I, Company_master C
  4  WHERE I.Company_code = C.Com_id
  5  GROUP BY C.Com_name;

COM_NAME                       AVERAGE_PRICE
------------------------------ -------------
Samsung                                  400
Apple                                    800
Dell                                     350
HP                                       400

4 rows selected.
```

### Calculation

* Samsung → `(300 + 500) / 2 = 400`
* Apple → `(700 + 900) / 2 = 800`
* Dell → `(400 + 300) / 2 = 350`
* HP → `(350 + 450) / 2 = 400`

# iv. Display company names whose average product price is >= Rs. 350

Use `HAVING` with `AVG()`.

### Query

```sql
SQL> SELECT C.Com_name,
  2         AVG(I.Price) AS Average_Price
  3  FROM Item_Master I, Company_master C
  4  WHERE I.Company_code = C.Com_id
  5  GROUP BY C.Com_name
  6  HAVING AVG(I.Price) >= 350;

COM_NAME                       AVERAGE_PRICE
------------------------------ -------------
Samsung                                  400
Apple                                    800
Dell                                     350
HP                                       400

4 rows selected.
```
