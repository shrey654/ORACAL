# Q15 — Customer & Salesman

## 1. Create Tables

### Customer Table

```sql
CREATE TABLE Customer
(
    C_id        NUMBER(5) PRIMARY KEY,
    Cname       VARCHAR2(30),
    City        VARCHAR2(20),
    Grade       NUMBER(5),
    Salesman_id NUMBER(5)
);
```

### SQL*Plus Output

```text
Table created.
```

---

### Salesman Table

```sql
CREATE TABLE Salesman
(
    Sid        NUMBER(5) PRIMARY KEY,
    Name       VARCHAR2(30),
    City       VARCHAR2(20),
    Commission NUMBER(5,2)
);
```

### Output

```text
Table created.
```

# iii. Customers in New York having grade above 100

### Query

```sql
SELECT *
FROM Customer
WHERE City = 'New York'
AND Grade > 100;
```

### Output

```text
C_ID  CNAME  CITY       GRADE  SALESMAN_ID
----  -----  ---------  -----  -----------
3001  Anil   New York    200       5001
3005  Neha   New York    250       5003

2 rows selected.
```

### याद रखने वाला point

Yahan **AND** use hua hai because both conditions true honi chahiye:

```text
City = New York
AND
Grade > 100
```

# v. Display customer name, city and grade with highest grade first

Question me **highest grade first** hai, so descending order use karenge.

### Query

```sql
SELECT Cname, City, Grade
FROM Customer
ORDER BY Grade DESC;
```

### Output

```text
CNAME    CITY       GRADE
-------- ---------- -----
Amit     Delhi       300
Neha     New York    250
Anil     New York    200
Meena    Mumbai      200
Priya    Mumbai      150
Kiran    Rajkot      100
Rohan    Delhi        50

7 rows selected.
```

### Important

```sql
ORDER BY Grade DESC;
```

`DESC` = **Highest to Lowest**

While:

```sql
ORDER BY Grade ASC;
```

`ASC` = **Lowest to Highest**

# vi. Customer name and salesman name situated in same city

Yahan Customer aur Salesman dono ka **city same** hona chahiye.

### Query

```sql
SELECT C.Cname AS Customer_Name,
       S.Name AS Salesman_Name,
       C.City
FROM Customer C, Salesman S
WHERE C.Salesman_id = S.Sid
AND C.City = S.City;
```

### SQL*Plus Output

```text
CUSTOMER_NAME  SALESMAN_NAME  CITY
-------------  -------------  ---------
Anil           Amit           New York
Priya          Rahul          Mumbai
Kiran          Suresh         Rajkot
Neha           Karan          New York
Meena          Rahul          Mumbai

5 rows selected.
```
