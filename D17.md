# (17) Employee Details

### Table: `emp_details`

Fields:

* `Emp_no`
* `Fname`
* `Lname`
* `Emp_dept`

---

## 1. Create Table

```sql
SQL> CREATE TABLE emp_details
  2  (
  3     Emp_no   NUMBER(5) PRIMARY KEY,
  4     Fname    VARCHAR2(30),
  5     Lname    VARCHAR2(30),
  6     Emp_dept NUMBER(5)
  7  );

Table created.
```

# i. Find last name of all employees without duplicate

Use `DISTINCT` to remove duplicate last names.

### Query

```sql
SQL> SELECT DISTINCT Lname
  2  FROM emp_details;

LNAME
------------------------------
Makwana
Joshi
Doshi
Patel
Shah

5 rows selected.
```

### Explanation

```sql
DISTINCT
```

means **don't repeat duplicate values**.

```sql
SQL> SELECT *
```

# iii. Display employees whose last name is Doshi or Joshi

### Query

```sql
SQL> SELECT *
  2  FROM emp_details
  3  WHERE Lname = 'Doshi'
  4     OR Lname = 'Joshi';

    EMP_NO FNAME                          LNAME                         EMP_DEPT
---------- ------------------------------ ------------------------------ --------
       102 Rahul                          Joshi                               58
       103 Amit                           Doshi                               57
       105 Priya                          Joshi                               57
       107 Neha                           Doshi                               58

4 rows selected.
```

### Alternative using `IN`

This is shorter and exam-friendly:

```sql
SELECT *
FROM emp_details
WHERE Lname IN ('Doshi','Joshi');
```
