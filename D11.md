# (11) Student, Fee & Course Tables

## 1. Create `Course_Master`

```sql
CREATE TABLE Course_Master
(
    C_code VARCHAR2(10) PRIMARY KEY,
    C_name VARCHAR2(30)
);
```

## 2. Create `Student_Master`

```sql
CREATE TABLE Student_Master
(
    Sno   NUMBER(5) PRIMARY KEY,
    Sname VARCHAR2(30),
    C_code VARCHAR2(10),
    City  VARCHAR2(20),
    Age   NUMBER(2),
    CONSTRAINT fk_student_course
    FOREIGN KEY (C_code)
    REFERENCES Course_Master(C_code)
);
```

## 3. Create `Fee_Master`

```sql
CREATE TABLE Fee_Master
(
    Sno NUMBER(5),
    Fee NUMBER(8,2),
    CONSTRAINT fk_fee_student
    FOREIGN KEY (Sno)
    REFERENCES Student_Master(Sno)
);
```

# i. Display all students whose fees is not paid

Students whose `Sno` is **not present in Fee_Master** have not paid their fees.

### Query

```sql
SELECT Sname
FROM Student_Master
WHERE Sno NOT IN
      (SELECT Sno FROM Fee_Master);
```

### SQL*Plus Output

```text
SQL> SELECT Sname
  2  FROM Student_Master
  3  WHERE Sno NOT IN
  4        (SELECT Sno FROM Fee_Master);

```

# iii. Display students course-wise

Join `Student_Master` with `Course_Master` and order by course.

### Query

```sql
SELECT C.C_name, S.Sname
FROM Student_Master S, Course_Master C
WHERE S.C_code = C.C_code
ORDER BY C.C_name;
```

# iv. Display student name, course name and age where age > 23 and < 27 and doing BCA

Conditions:

```text
Age > 23
Age < 27
Course = BCA
```

### Query

```sql
SELECT S.Sname,
       C.C_name,
       S.Age
FROM Student_Master S, Course_Master C
WHERE S.C_code = C.C_code
AND S.Age > 23
AND S.Age < 27
AND S.C_code = 'BCA';
```
