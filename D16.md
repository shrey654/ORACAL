## 2. Create Customer Table

```sql
SQL> CREATE TABLE Customer
  2  (
```

# I. Find names of all customers along with salesman who works for them

### Query

```sql
SQL> SELECT C.Cname AS Customer_Name,
  2         S.Name AS Salesman_Name
  3  FROM Customer C, Salesman S
  4  WHERE C.Salesman_id = S.Sid;

Priya                           Rahul

```

# II. Display all salesman and customer located in London using UNION

Here we select **names** of both Salesman and Customer whose city is London.

### Query

```sql
SQL> SELECT Name AS Person_Name
  2  FROM Salesman
  3  WHERE City = 'London'
  4  UNION
  5  SELECT Cname
  6  FROM Customer
  7  WHERE City = 'London';

PERSON_NAME
------------------------------
Karan
Neha
Ravi

3 rows selected.
```

### Explanation

`UNION` combines the result of two `SELECT` statements and removes duplicate values.
