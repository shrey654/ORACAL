## (10) Deposit–Branch–Customer–Borrow

### 1. Create `Branch` table

```sql
CREATE TABLE Branch
(
    Bname VARCHAR2(20) PRIMARY KEY,
    City  VARCHAR2(20)
);
```

### 2. Create `Customer` table

```sql
CREATE TABLE Customer
(
    Cname VARCHAR2(20) PRIMARY KEY,
    City  VARCHAR2(20)
);
```

### 3. Create `Deposit` table

```sql
CREATE TABLE Deposit
(
    Ac_no  NUMBER(5) PRIMARY KEY,
    Cname  VARCHAR2(20),
    Bname  VARCHAR2(20),
    Amount NUMBER(10,2),
    Adate  DATE,
    CONSTRAINT fk_dep_branch FOREIGN KEY (Bname)
        REFERENCES Branch(Bname)
);
```

### 4. Create `Borrow` table

```sql
CREATE TABLE Borrow
(
    Loanno NUMBER(5),
    Cname  VARCHAR2(20),
    Bname  VARCHAR2(20),
    Amount NUMBER(10,2),
    CONSTRAINT fk_bor_customer FOREIGN KEY (Cname)
        REFERENCES Customer(Cname),
    CONSTRAINT fk_bor_branch FOREIGN KEY (Bname)
        REFERENCES Branch(Bname)
);
```

# i. Customers living in Mumbai and Branch city Nagpur

We need to join `Customer` → `Borrow` → `Branch`.

### Query

```sql
SELECT DISTINCT C.Cname
FROM Customer C, Borrow B, Branch BR
WHERE C.Cname = B.Cname
AND B.Bname = BR.Bname
AND C.City = 'Mumbai'
AND BR.City = 'Nagpur';
```

### SQL*Plus Output

```text
SQL> SELECT DISTINCT C.Cname
  2  FROM Customer C, Borrow B, Branch BR
  3  WHERE C.Cname = B.Cname
  4  AND B.Bname = BR.Bname
  5  AND C.City = 'Mumbai'
  6  AND BR.City = 'Nagpur';

no rows selected
```

With the sample data above, there is no Mumbai customer borrowing from a Nagpur branch.

# iv. Borrowers having deposit amount > 1000 and loan amount > 2000

### Query

```sql

FROM Borrow B, Deposit D
WHERE B.Cname = D.Cname
AND D.Amount > 1000
AND B.Amount > 2000;
```
