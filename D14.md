# Q14. Create Table and Solve Queries

## 1. Create `Orders` Table

Oracle me `ORDER` reserved keyword hai, isliye table ka naam **Orders** rakhenge.

```sql
CREATE TABLE Orders
(
    Ord_no       NUMBER(5) PRIMARY KEY,
    Purch_amt    NUMBER(10,2),
    Ord_date     DATE,
    Customer_id  NUMBER(5),
    Salesman_id  NUMBER(5)
);
```

### SQL*Plus Output

```text
Table created.
```

# i. Display columns in specific order

Question asks:

**Order Date → Salesman ID → Order Number → Purchase Amount**

### Query

```sql
SELECT Ord_date,
       Salesman_id,
       Ord_no,
       Purch_amt
```

# ii. Display salesman IDs without repetition

Question: Orders table se **all salesman IDs**, but duplicate nahi chahiye.

### Query

```sql
SELECT DISTINCT Salesman_id
FROM Orders;
```

### SQL*Plus Output

```text
SALESMAN_ID
-----------
       5001
       5002
       5003
       5004

4 rows selected.
```

### Important

`DISTINCT` ka use **duplicate values remove karne ke liye** hota hai.

For example:

```text
5001
5002
5001
5003
5002
```

becomes:

```text
5001
5002
5003
```

# iii. Orders delivered by salesman ID 5001

Question asks:

* Order number
* Order date
* Purchase amount
* Salesman ID = 5001

### Query

```sql
SELECT Ord_no,
       Ord_date,
       Purch_amt
FROM Orders
WHERE Salesman_id = 5001;
```

### SQL*Plus Output

```text
ORD_NO  ORD_DATE   PURCH_AMT
------  ---------  ---------
70001   10-JAN-26       1500
70003   15-JAN-26       2500
70006   22-JAN-26        950

3 rows selected.
```

### Simple Explanation

```sql
WHERE Salesman_id = 5001
```

ka matlab hai **sirf salesman ID 5001 ke orders select karo**.
